# Hex Cell Map v0.1.0

The first release generates editable 3D hex maps from real GIS data in a native Rust + Bevy application.

- Select a geographic rectangle and generate terrain from Copernicus DEM, ESA WorldCover, HydroRIVERS and GeoNames.
- View continuous terrain, connected river channels and lakes, forest scenery and urban building clusters.
- Edit urban cells with undo/redo, adjust display heights, and save self-contained projects for offline use.
- Switch between English and Simplified Chinese using the embedded translations and Chinese font.
- Process GIS samples and terrain chunks in parallel while preserving deterministic results.
- Read the illustrated data pipeline and core algorithm documentation in English or Simplified Chinese.

## Downloads

| Platform | Archive |
| --- | --- |
| Windows x64 | `hex-cell-map-v0.1.0-windows-x64.zip` |
| macOS Apple Silicon | `hex-cell-map-v0.1.0-macos-arm64.zip` |

Each archive includes the desktop application, `gis-probe`, art assets, the PROJ database, documentation and dependency notices. Windows includes the MSVC runtime DLLs. The accompanying `.sha256` files contain archive checksums.

Extract the Windows ZIP and launch `hex-cell-map.exe`. On macOS, extract the ZIP and move `Hex Cell Map.app` to Applications. The macOS bundle is ad-hoc signed and not notarized; macOS may require approving it in Privacy & Security before the first launch.

Initial map generation needs internet access. Saved projects reopen without GIS caches. Supported selections use 1–20 km center spacing, at most 1,000 km extent and 100,000 cells, latitude within ±60°, and no antimeridian crossing.

## Validation and scope

CI builds and tests both native targets, runs Clippy, verifies bundled art, and extracts each ZIP into a temporary directory to test GIS drivers, projection-data discovery, application startup arguments in both languages, and required runtime files. macOS archive verification also checks the bundle signature.

Interactive terrain rendering has been validated on macOS Apple Silicon. Windows interactive GPU validation, installation on separate clean machines, release performance at 100,000 cells, and release signing/notarization remain open validation gates. General elevation brushes and broader project workflows are planned; this initial release provides urban editing and display-height controls.
