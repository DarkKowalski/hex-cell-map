# Chinese UI font

`NotoSansSC-Regular.otf` is the unmodified Simplified Chinese subset of Noto Sans CJK, version 2.004, from the [Noto CJK repository](https://github.com/notofonts/noto-cjk).

- Source: [NotoSansSC-Regular.otf at f8d157532fbfaeda587e826d4cd5b21a49186f7c](https://raw.githubusercontent.com/notofonts/noto-cjk/f8d157532fbfaeda587e826d4cd5b21a49186f7c/Sans/SubsetOTF/SC/NotoSansSC-Regular.otf).
- SHA-256: `faa6c9df652116dde789d351359f3d7e5d2285a2b2a1f04a2d7244df706d5ea9`.
- Copyright: © 2014–2021 Adobe (http://www.adobe.com/), as recorded in the font's original metadata.
- License: SIL Open Font License 1.1; the upstream text is in [OFL.txt](OFL.txt).

The font is stored with Git LFS. Run `git lfs pull` before building. The desktop executable embeds it as a fallback for proportional and monospace UI text, including Chinese place names, without relying on installed system fonts.
